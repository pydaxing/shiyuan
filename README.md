## 关于食愿

> 「今天吃啥？」
> 「都行，你定。」
> 到了晚上，又是同样的问题。

两个人也好，一家人也好，每天吃什么，是一个小问题，却要每天重新做决定。想吃的人一时没有主意，做饭的人除了下厨，还要想菜单、记住大家的口味、确认材料够不够。

**食愿是一款兼顾个人与家庭的饮食规划、菜谱和餐食记录小程序。一个人认真吃饭，一家人一起安排。**

把喜欢的菜收进自家菜单，家人挑选想吃的菜，在「小灶」汇成同一餐，再按菜准备食材。负责点菜的人有具体的选择，负责做饭的人能看到这一餐的安排；菜谱、用量和餐食记录也有了共同的去处。

没有灵感时，就去「美食」看看别人家的拿手菜。喜欢的做法可以加入自家菜单，按家人的口味修改；自己做得好的菜也可以分享出去。

> 把想吃的，变成一起吃的。让好好吃饭这件事，少一些纠结，多一些参与。

## 一家人的日常

### 从想吃，到记下这一餐

**收进菜单 → 安排日期和餐次 → 按菜备料 → 拍照记录 → 回看饮食日记**

- **自己用，也能一起用。** 个人菜单和餐食安排独立；加入家庭后，家人可以在共同的小灶中安排一餐。
- **先把菜记下来。** 创建和整理菜品、套餐，按类别找回喜欢的味道；菜谱中的食材与做法也方便下厨时查看。
- **安排更有着落。** 按日期和餐次选菜，做饭前查看备菜清单和食材用量。
- **从美食寻找灵感。** 浏览公开菜谱，把喜欢的做法加入自己的菜单，也可以分享做得好的菜。
- **把一餐留下来。** 上传实拍或记录安排，在发现中分享日常，也能回看自己的饮食日记。

### 四个入口，各有一件日常事

| 入口 | 能做什么 |
| --- | --- |
| **小灶** | 浏览菜单、创建菜品和套餐、安排餐食、查看备菜清单。 |
| **美食** | 浏览公开菜谱与做法，收藏喜欢的菜。 |
| **发现** | 看看大家正在吃什么，分享自己的餐食。 |
| **我的** | 管理个人资料与家庭，进入饮食日记。 |
