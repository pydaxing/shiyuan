## 一家人的日常

从菜单里挑选菜品和套餐，按日期与餐次安排；做饭前查看食材与用量。也可以浏览公开美食，把喜欢的做法收入菜单，记录并回看每一餐。在个人与家庭模式间切换，让一个人吃饭或一家人一起安排都方便。
