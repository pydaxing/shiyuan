# 食愿小灶

一个人认真吃饭，一家人一起安排。

食愿小灶是一款面向个人与家庭的饮食规划小程序：收好喜欢的菜、安排每一餐、按菜备料，也把一起吃饭的日常记下来。

## 体验小程序

打开微信搜索 **「食愿小灶」**，或扫描下方小程序码体验。

![食愿小灶小程序码](docs/images/promotion/mini-program-code-1280.jpg)

## 现在能做什么

- 创建、收藏和整理菜品与套餐
- 按日期和餐次安排家庭餐食，查看备菜清单
- 浏览公开美食，将喜欢的做法加入自己的菜单
- 记录餐食、分享日常，并回看饮食日记
- 在个人与家庭模式间切换，管理成员与资料
