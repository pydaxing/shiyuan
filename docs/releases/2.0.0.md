## 主要变化

### 个人与家庭各有自己的小灶

普通首次进入默认个人模式；通过有效家庭邀请完成加入后开启家庭模式。个人与家庭的菜单、安排按空间区分，在「我的」中管理资料、家庭和模式。首次进入提供默认头像与昵称，用户可以自行修改。

### 快速记菜，再慢慢完善做法

菜品只需封面、名称、类别即可保存，时长不填按 20 分钟记录。食材与做法收在可展开区域，适合先把常吃的菜放进菜单，再补充细节。发布到美食前会检查封面、食材与步骤；不完整的自建菜也可以分享给微信好友。

美食未修改地加入菜单时沿用原菜品身份。真正编辑内容后生成自建菜，原公开菜谱不会被静默改写。菜单和安排用来源标签区分美食与自建；套餐用于组合选菜，进入安排后按菜品处理。

### 安排、记录与发现

小灶包含菜单与安排，选择日期和餐次后确认安排；备菜清单按菜展示材料和用量。记录页可以从安排进入，也可以在发现中选择安排或直接上传实拍。

发现展示公开餐食与点赞。美食图片进入统一菜谱详情，自建菜与实拍图打开大图，旧数据中没有图片的菜保留名称，不用默认封面伪装原图。公开餐食不会自动把自建菜谱发布到美食。

### 家庭共享与个人饮食日记

家庭餐食以共同记录保存，关联当时成员的个人日记。成员切回个人模式仍可回看自己关联的家庭餐食；新加入的成员不会自动得到所有历史餐食的个人归档。

记录可以公开到发现，也可以仅留在饮食日记。未手动记录的有效安排跨天后自动归档，默认公开；已有记录继续保留原先可见范围。自动归档由定时任务逐批执行，不保证零点瞬间完成。

家庭日记删除主记录，同步影响关联成员的个人日记；个人日记移除家庭餐食，仅隐藏自己这一份关系。已删除餐食不会被自动归档重新补回，管理操作仍检查操作者权限。

### 退出家庭的保留规则

家庭仍有其他成员时，退出不解散家庭；创建者退出时由剩余成员接任。最后一人可以退出，家庭随后进入清理流程。家庭菜单、安排等工作数据会清理；已公开内容及符合参与者归档条件的共享餐食按保留规则处理，避免个人饮食历史被一并抹去。不是所有旧私密记录都自动转为共享或保留。

退出确认提示已改为说明这些保留边界，不再笼统声称清空所有日记。
