# 厨房加菜接口修复 · 2026-10-21

## 原因和范围

加菜弹窗提交 `command / addOrderDishes`，但实际部署的 `kitchen-v2` 仍是 2026-10-20 的食材单位兼容版本，没有注册该操作。因此请求在执行订单逻辑前就返回“不支持的操作”。重新编译小程序不能补齐云端接口。

本次以下载的线上代码为基线，只更新 `index.js`：注册加菜操作、校验菜品/套餐选择、在家庭事务中追加选菜、允许并发加菜安全合并，并禁止已开始备菜的餐次通过加菜或旧点餐入口修改。新入口直接复用 `src/domain/meal-additions.js` 的追加逻辑。

原餐次 ID、自己已有的选菜和备注、家人的选菜、历史菜谱快照均保留。同菜多人选择不会重复计算食材；请求重试不重复写入。加菜不扣库存、不改采购记录或功能开关。线上图片加密、私有图片分发、食材单位兼容入口、运行环境和依赖未更换。
