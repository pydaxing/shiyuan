# 发现下拉刷新切页留白修复（2026-11-09）

## 原因和改动

上次使用 Vue `:key` 重建 scroll-view，但微信产物将其编译成普通 `key` 属性，原生滚动容器并未销毁，隐藏后可能保留下拉偏移。此次改用 `v-if="active"`，产物确认生成原生 `wx:if`。离开时无条件重置刷新状态，也覆盖尚未达到刷新阈值的下拉和恢复动画阶段；保留公共列表缓存及已保存滚动位置。

只修改 MealSquare 生命周期，不改刷新请求、分页和业务数据。
