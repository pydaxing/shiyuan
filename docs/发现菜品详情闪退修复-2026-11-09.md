# 发现菜品详情闪退修复（2026-11-09）

## 原因与修改

首页向 MealSquare 传入的 active 同时依赖发现标签和 !sheetOpen。发现列表为清理原生刷新残留而在 inactive 时卸载 scroll-view；卡片内打开 FoodDetailSheet 注册 sheet 后，active 立即变 false，列表和详情一起销毁。

active 现在仅代表是否处于发现标签；MealSquare 原有 feedLocked 继续根据 sheetOpen 禁止背景滚动与刷新。真正切换标签仍卸载原生 scroll-view，保留刷新残留清理策略。仅修改该绑定，未改餐食数据、详情请求、权限或云函数。
