# 删除安排后保留发现菜品标记与做法（2026-11-09）

## 原因
餐食持久化只保存 recipeId、标题和封面，mealDishSources 依赖仍存在的 orders 快照。用户从个人日记移除餐食后删除安排，公共餐食仍然存在，但来源和做法无法读取。

## 修改
- 手动发布安排菜品、自动归档均独立保存内部 recipeSnapshots。公共列表不输出快照中的食材、来源或其他内部字段，详情仍使用既有字段白名单及图片权限检查。
- 修改或删除旧安排前，在同一事务内为关联的公开餐食保留原菜谱快照；后续减菜、删掉最后一道菜和删除安排不再丢失来源。日记隐藏不影响公共餐食。
- 对已经删掉安排且没有快照的旧记录，仅从当前空间准确 ID 的新版公开导入菜恢复；要求封面、标题和公开菜内容一致，公开源仍可访问。不会按同名猜测、读取私有改版或将自建菜冒充原菜。
