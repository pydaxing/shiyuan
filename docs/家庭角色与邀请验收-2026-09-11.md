# 家庭角色与邀请验收

## 界面与用法

- 家庭设置的「切换与管理」使用家庭封面作为头像。无封面时使用稳定的默认头像；新建家庭从六款原创插画中随机选一款，可在创建前更换。
- 当前家庭显示「使用中」及浅绿勾选圆标，其余家庭显示空心圆，整行点击切换。
- 家人以四列头像网格排列。管理员点成员头像打开称号、转交管理员、移出家庭操作；不允许移除自己。
- 「一家之主」是可选、唯一的展示称号，与权限管理员分开。只有管理员可设置、替换或取消。称号在管理网格和家庭页成员头像上显示皇冠，可与大厨帽共存；厨房订单头像不加皇冠。
- 管理员有并排的「退出家庭」「删除家庭」入口；普通成员只显示退出。删除要求准确输入家庭名称。
- 管理员退出必须指定接任者，转交和退出原子完成。只有自己时显示先邀请家人或删除的引导，不能留下无管理员的家庭。
- 家庭管理的子页面切换会回到面板顶部，不重建 Sheet，不丢失名称与封面的编辑草稿。

## 权限与数据

- 云端动作新增 `setFamilyHead`、`transferFamilyOwner`。`leaveFamily` 支持 `successorId` 与 `expectedOwnerId`；拒绝外部成员接任、旧管理员操作和跨家庭过期请求。
- 创建保存 `family.avatar`；称号保存 `family.headMemberId`。旧数据无需批量改写，读取时按家庭标识稳定选择默认头像。
- 成员退出、移除或管理员转交会撤销旧邀请。离开的成员若是一家之主，同时清除称号；其他家庭、订单和日记保留。
- 非当前家庭的私有图片只额外放行「本人仍在其中的家庭的当前封面」，不开放其余家庭照片。公开菜品及好友分享的图片授权维持原来的独立范围。
- 邀请入口在丢失管理员身份时清除准备状态；成员变更后重新取得有效卡片，防止继续转发已撤销邀请。失败可重试并显示实际错误。
