# 家庭设置隔离与删除确认修复 · 2026-09-14

## 问题与处理

用户确认其他输入基本正常，本轮只处理家庭设置的两个问题，不修改共享 FormField、Sheet 或键盘滚动逻辑。

### 名称与封面下方残留管理内容

FamilyManagement 的 `active` 属性被同名局部生命周期变量遮蔽。模板实际上一直读取局部的 true，父组件切回外观页并传入 false 也无法移除管理页内容。

局部变量改名为 alive，模板显式读取 props.active。管理组件仍保留已加载的家庭列表，但非当前页的原生节点和输入框会卸载，外观草稿不丢失。

新增编译模板行为测试：真实编译 Vue 模板并交替传入 active，而非只检查源码中是否出现 v-if。该测试在旧实现上失败，修复后通过。

### iPhone 删除确认输入失焦

开发者工具中旧输入可以键入，未取得 iPhone 的完整焦点时序，不能断言某个延时就是唯一原因。本轮不再继续调整已经正常的共享输入控件，而是移除删除路径中的自定义弹层输入，使用微信原生 editable showModal。

流程：点击删除家庭 → 阅读不可撤销说明 → 继续 → 在原生弹窗手动输入家庭名称 → 删除或取消。名称只作为 placeholder，不自动填入。原生输入的键盘和布局由微信处理，不再参与 Sheet 的滚动定位。

保留管理员权限与完整名称校验；空值、部分名称、前后多空格均不能删除。两个确认阶段都可取消；操作中锁定切换和重复点击；弹窗失败会解锁并提示。等待期间家庭、名称、权限发生变化或组件已卸载时不会提交。原有未保存外观的放弃确认仍保留。
