# 广场原作者展示

## 展示与权限

- 官方导入菜品的广场卡片和详情显示下厨房原作者，取自 `recipes[0].provenance.attribution`；例如“熊猫吐司”显示“小美好曾曾”。普通用户自己分享的菜品仍显示自己的发布名称。
- 移除菜品详情中的“来源与改编说明”模块。数据库中的来源、作者、原链接和授权说明保留，供后台追溯。
- 展示名不代表操作权限。导入菜品仍由 `official:shiyuan` 管理，普通用户及昵称相同的用户均不能删除。
- 广场列表、详情缓存升级到 v3，避免新客户端使用旧作者缓存。不清除家庭数据和图片缓存。
