# 手机号登录接入（2026-11-09）

本轮只接入手机号，位置授权和位置保存暂不实现。

## 入口规则

- 普通入口、菜品分享入口、家庭邀请入口共用封面登录页。未绑定手机号的新老用户都先登录，再继续原入口；邀请 token 和分享目标保留。
- 已绑定用户每次冷启动从服务端核对绑定状态，随后直接进入；同一运行会话合并核对请求，不重复要求手机号授权。
- 勾选隐私协议后，由微信原生 getPhoneNumber 按钮获取一次性 code，后端调用 phonenumber.getPhoneNumber。取消不放行；网络失败可重试，响应丢失先查询绑定状态，不重放 code。
- 身份继续由微信 OPENID 派生，不以手机号重建或合并用户。原昵称、头像、家庭关系、餐食数据保持。
- 手机号保存在 users.privateContact，包含国家码、验证时间与协议版本。状态接口只返回绑定状态，不返回号码；不放入家庭、发现、分享或资料响应。
- 兼容旧版本：新版请求携带 accountLoginVersion=1，bootstrap 强制验证；旧版协议继续原行为。新版客户端所有业务云请求均等待登录完成。
