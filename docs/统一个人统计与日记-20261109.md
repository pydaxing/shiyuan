# 统一个人统计与饮食日记

2026-11-09 按用户新规则调整。源码版本 2.0.2，本轮未上传微信开发包或提审。

## 数据口径

每个用户只有一份相伴、开火、获赞汇总，两种模式展示相同数字。相伴按北京时间本人实际前台到访日去重，停止累加旧的分家庭到访字段；既有个人相伴并集保留。旧版未完整记录每日访问，无法准确回填历史相伴天数，不使用注册年龄或自动归档日期冒充实际访问。

开火和获赞使用已发布个人餐与本人参与家庭餐的日记并集，按餐食 ID 去重，排除已删除记录和本人的隐藏标记。一个家庭餐只保存一条原始记录，参与者共享其获赞数；他人个人餐不进入当前用户汇总。

新版通过 `userSummaryVersion: 1` 获取统一汇总及日记。老客户端不传该参数时保持旧列表和餐食统计协议。访问计数服务统一返回个人并集。统计缓存和到访缓存按用户隔离，切换模式不清空已加载数字；服务端仍核验当前空间，客户端丢弃过期请求结果。

日记在两种模式均展示同一份混合列表；家庭模式也归档本人的个人安排。记录时仍由当前模式决定归属和发现页署名。两种发布入口复用服务端发布流程，家庭参与者由服务器取成员列表，不接受客户端伪造。

删除沿用原规则：个人模式隐藏家庭餐只影响本人的统一日记；当前家庭模式删除该家庭原始餐食影响全部成员；自己的个人餐在任何模式都只删除本人记录。家庭模式中混合出现的个人餐及旧家庭餐，按其真实来源计算操作权限。
