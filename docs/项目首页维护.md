## 手机边框与保真

继续使用原有 iPhone 17 标准版边框。它是界面与边框合成效果图，不是真机拍摄。来源与许可沿用 2026-10-28 的核对记录：WebMobileFirst Apple iPhone 17 页面提供的 388 × 800 透明 PNG，许可允许合成使用，不允许再分发独立边框。独立边框只放在忽略目录 artifacts/readme-showcase-20261028/device-source/iphone17.png，不入库。

脚本 scripts/build-readme-phones.mjs 去除模拟器系统刘海区域，将整个应用区域等比例放入边框安全矩形，再分别处理系统时间、状态和手势区域。没有裁掉或重画应用正文。新增加的 728 × 1576 输入尺寸支持只影响文档图片脚本。

再生成：

```sh
node scripts/build-readme-phones.mjs \
  --frame artifacts/readme-showcase-20261028/device-source/iphone17.png \
  --source-dir docs/images/readme/v2 \
  --output-dir docs/images/readme/v2 \
  menu arrange preparation food discovery record diary profile
```

[像素保真报告](images/readme/v2/phone-composition-report.json) 中八张图的 frameOrMaskChangedApplicationPixels 均为 0。该检查验证合成边框没有覆盖应用像素，不能替代业务验收。
