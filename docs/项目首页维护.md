# 项目首页维护

README 是「食愿」的产品介绍入口，运行环境、接手规则和发布操作放在 [开发接手指南](开发接手指南.md) 与 [版本与发布](版本与发布.md)。历史 README 保存在 [归档](history/README-2026-10-28.md)。

## 封面与品牌

首页沿用 `assets/brand/shiyuan-icon-v2-1024.png` 的「家、爱心、饭碗」图标，配合应用现有的蓝灰配色。`docs/images/readme/cover.png` 与 `cover-dark.png` 分别用于浅色、深色 GitHub 主题，`cover-compact.png` 与 `cover-compact-dark.png` 用于窄屏；它们是品牌宣传图，不是运行界面截图。

执行以下命令可以重绘封面与徽章，不会构建或部署小程序：

```sh
node scripts/build-readme-art.mjs
```

封面字体使用 macOS 的宋体与系统中文黑体，生成好的 PNG 已入库，浏览者和新电脑无需安装字体即可查看。其他系统重新生成时可能使用后备字体，请检查字形与排版。

## 界面图片

`discover.png` 与 `recipe.png` 来自 2026-10-28 微信开发者工具中 `dist/release` 的真实云端界面，分别展示美食推荐页、菜谱详情页。原始记录为本机忽略目录里的 `artifacts/production-release-20261028/live-recommended.png` 和 `artifacts/family-release-audit-20261028/final-community-detail.png`；仓库内图片可独立显示，不依赖这些原始目录。

图片只做展示尺寸和编码处理，未伪造菜单、家庭或订单。截图中的菜谱图文和署名保持原界面归属，仅用于展示产品体验；项目代码的授权不能替代这些内容的授权。后续换图应继续使用真实微信界面，检查个人资料、邀请码和内部数据后再提交。

## 顶部小标签（Badges）

徽章可以用 Shields.io 的图片地址，也可以使用仓库内的 SVG。当前选用本地 SVG，避免私有仓库的动态查询权限问题。版本徽章读取 `package.json`，其他徽章标注实际技术栈。更新版本后重新运行上面的脚本并提交产物，同时检查 README 中版本图片的 `alt` 替代文本。

```html
<img src="docs/images/readme/badges/version.svg" alt="源码版本 1.0.0" height="24" />
```

当前没有 LICENSE 文件，因此没有添加 MIT 或其他开源许可证徽章。将来确定授权方式时，应先落实 LICENSE 与第三方资源边界，再添加对应徽章。没有接入 CI 时也不显示自动构建通过或覆盖率徽章；源码版本徽章不代表微信正式版已发布。
